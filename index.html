npm as Destination

Make your design token distribution even more flexible
and customizable using only one configuration. The
package can be reused by multiple teams and projects.

Notion as Destination

From today onwards you are able to use Specify
together with Notion! Start creating your own design
data documentation in Notion, it’s only a click away.

We built an entirely new format to base our platform on,
compatible with Aliases and Modes, increasing
collaboration between designers and engineers.
